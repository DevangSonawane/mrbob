## Liquid Glass Widgets reference
This project vendors reference material for `liquid_glass_widgets`
(^1.7.2) under `docs/vendor/liquid_glass_widgets/`. Before writing or
modifying any glass UI (nav bars, search bars, cards, sheets, menus),
read `.claude/skills/liquid-glass-widgets/SKILL.md` first, then check
`docs/vendor/liquid_glass_widgets/demos/` for a matching pattern before
writing custom code. Do not hand-roll BackdropFilter/shader effects when
a real package component already covers the use case.
